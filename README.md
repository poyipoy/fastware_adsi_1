# Fastware ADSI

Fastware ADSI is a Laravel-based internal web application designed to support administrative workflows, operational monitoring, and business reporting.

## Main Features

- CRM report and sales visit monitoring
- Sales logbook and planned visit tracking
- Customer data management
- User and role-based access management
- Dashboard reporting and filtering
- Data export for business reports
- Operational data analysis for sales activities

## Tech Stack

- Laravel
- PHP
- MySQL
- Blade
- JavaScript
- Bootstrap
- DataTables

## Goal

This project aims to centralize operational data, reduce manual reporting work, and provide structured insights for sales activity analysis and management decision-making.
